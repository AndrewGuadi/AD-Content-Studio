# understand.md — shared/2026-10-29/

## What this directory is

A dated snapshot (October 29, 2026) of the finished Authentic Dynamics
video deliverables, as zip archives. It exists so that Muse and GPT can
reference the actual media — not just descriptions of it — without anyone
having to re-render, re-download, or re-derive the files from Instagram.

## Where it fits in the larger repo

- `muse/content-inventory.md` is the running track of what exists and its
  status. This directory is the media that track points to.
- `shared/` holds editorial material both agents use (workflow, calendars).
  This dated folder is the media snapshot that sits alongside them.
- `GPT/` holds GPT's editorial records and roadmaps; `Muse/` is Muse's
  working placeholder. Neither holds finished video — this folder does.
- The full-quality originals remain in Muse's workspace. These zips are
  copies of those originals, not replacements for them.

## Why six zips instead of one

A single zip of all deliverables would be ~104 MB. GitHub blocks files
over 100 MB as regular repo files, and its web upload path warns above
25 MB. So the set is split by series/project, each zip under 25 MB.
Video files are already compressed, so zipping does not shrink them —
the split is about the hosting limits, not compression.

## What is deliberately NOT here

- Scene fragments, silent renders, and intermediate working cuts.
- Superseded voice cuts (placeholder-voice, Aiden cuts) — the shipped
  cloned-voice cuts are the ones archived.
- Digital, Explained source downloads — those episodes are already public
  on Instagram and are tracked in the inventory, not re-archived here.
- Third-party test fixtures and library sample videos found in the
  workspace — not Authentic Dynamics content at all.
