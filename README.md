## Standing operating rules
- Every social publish, deletion, message or account-settings change requires specific owner approval; drafts and plans are not approval.
- No fabricated results, customer endorsements, facts, statistics or personal stories.
- Research and work from original evidence. Show gaps, especially paid versus organic audience metrics.
- Use real demonstrations and the founder's tone; label cloned/generated material and follow documented permissions.
- Don't commit credentials, account secrets, confidential data, private client material or non-public personal details. **This repository is public at last verification.**
- Muse describes a scheduled GitHub polling workflow, but says it has not yet been activated; don't assume live automatic synchronization.
